# BMI Calculator (Flask App)

A simple, responsive BMI (Body Mass Index) calculator built using **Python**, **Flask**, and **HTML/CSS**.  
This app takes your height and weight as input and calculates your BMI along with a health message and color-coded feedback.

# Features

- Calculates BMI using user input (Height in cm, Weight in kg)
- Displays results with color-coded categories:
  - **Blue** for Underweight
  - **Green** for Normal
  - **Orange** for Overweight
  - **Red** for Obese
-  Clean and responsive UI
-  Health tips based on BMI result
